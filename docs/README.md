# Documentação acadêmica do Cinemax

Arquivos preparados para cobrir os itens de Engenharia/Análise e Evolução da rubrica.

## Entregáveis

- `CONTEXTUALIZACAO.md` — problema, público, solução e objetivo.
- `EVOLUCAO.md` — evolução do produto.
- `REQUISITOS.md` — RF, RNF e regras de negócio.
- `DER.md` — diagrama entidade-relacionamento.
- `CASOS_DE_USO.md` — 2 diagramas.
- `ATIVIDADES.md` — 2 diagramas.
- `SEQUENCIA.md` — 2 diagramas obrigatórios + 1 adicional.
- `PERSONA.md` — persona e conexão com a proposta.
- `RASTREABILIDADE.md` — requisito → código/API/banco/teste.
- `TESTES_MOBILE.md` — checklist para registrar validação em aparelho real.

Os diagramas utilizam **Mermaid**, que é renderizado diretamente pelo GitHub em arquivos Markdown.

## Antes da entrega

1. Revisar nomes do grupo/instituição se houver capa externa.
2. Marcar os testes realmente executados em `TESTES_MOBILE.md`.
3. Conferir se o GitHub renderizou os blocos Mermaid.
4. Não declarar pesquisa/entrevista que não foi realizada.
